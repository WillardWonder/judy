# Judy's Pony World

A tiny, touch-first pony toy designed for a young child who is still learning to read.

## What it does

- Six big pony faces to tap and switch horses
- One large animated pony on screen
- Four picture actions: apple, brush, ride, and dress up
- Picture-only dress-up drawer with pony accessories
- Meadow, stable, and horse-show scenes
- Spoken pony names and actions using the browser's built-in speech
- Gentle sound effects made in the browser
- Progress saved automatically with localStorage
- Export/import backup hidden in grown-up settings
- No database, login, framework, or build step

## GitHub Pages

Upload `index.html`, `styles.css`, and `app.js` to the repository root. In GitHub, open Settings > Pages, choose **Deploy from a branch**, select the main branch and `/ (root)`, then save.

Progress stays on the same browser profile and device unless browser/site data is cleared. Use the grown-up gear to export a backup if desired.
