# Judy's Pony World

A tiny, touch-first pony toy designed for a young child who is still learning to read.

## What it does

- Six big pony faces to tap and switch horses
- One large animated pony on screen
- Four picture actions: apple, brush, ride, and dress up
- Trail Ride quest: help Bunny find carrots, swim out to rescue Mama Duck's ducklings, then open the island treasure. Tap anywhere (or on the minimap) to ride there; a pink arrow always points to the next goal
- Rodeo: pick any horse and a rider from the cast (dress riders in the Rider Closet), then try Barrel Racing, Trick Riding, Show Jumping, Calf Roping and Bronc Riding. Best scores and ribbons are saved
- My Ranch + barn: free roam with drawn farm animals, stalls with treats and grooming tools (Sparkle Spray makes a pony glitter for 15 minutes), and the Tack Room
- Star Run: tap to jump, tap again in the air to double-jump; jump the hay bales, grab the rainbow star magnet and lucky horseshoes
- Picture-only dress-up drawer with pony accessories
- Meadow, stable, and horse-show scenes
- Spoken pony names and actions using the browser's built-in speech
- Original music for every scene (meadow, bedtime lullaby, Trail Ride hoedown, Star Run, Pony Maze) plus sound effects for every action, all synthesized in the browser with no audio files
- Sound button (top right) cycles Music on → Sounds only → Quiet; the choice is remembered
- Progress saved automatically with localStorage
- Export/import backup hidden in grown-up settings
- No database, login, framework, or build step

## GitHub Pages

Upload `index.html`, `styles.css`, and `app.js` to the repository root. In GitHub, open Settings > Pages, choose **Deploy from a branch**, select the main branch and `/ (root)`, then save.

Progress stays on the same browser profile and device unless browser/site data is cleared. Use the grown-up gear to export a backup if desired.
